# LOKESH Portfolio
 portfolio for a web developer.

## Run locally

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Personalize before publishing

- Update project names, descriptions, links, and the email in `app/page.tsx`.
- Replace `APEX` in `app/layout.tsx` and navigation with the final personal brand.
- The 3D hero is an abstract original race-machine composed in `components/RaceMachine.tsx`; it is not a Red Bull asset or logo.
- Deploy to Vercel after final content and domain are ready.

## Stack

Next.js 14, React Three Fiber / Three.js, Drei, Framer Motion.
